# Bagels — Python Number Guessing Game

A text-based number guessing game built with Python. The player tries to guess a secret three-digit number using logical clues.

## How to Play

- The computer generates a secret three-digit number with no repeated digits.
- You have 10 attempts to guess the number.
- Enter your guess and use the clues to narrow down the answer.

## Clues

- **Fermi:** A digit is correct and in the correct position.
- **Pico:** A digit is correct but in the wrong position.
- **Bagels:** No digits are correct.

## Technologies Used

- Python
- `random` module
- Loops and conditional statements
- Strings and user input

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python bagels.py`
